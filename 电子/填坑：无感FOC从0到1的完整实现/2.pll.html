锁相环在无传感器FOC中的应用：从反电动势到角度跟踪

锁相环在无传感器FOC中的应用：从反电动势到角度跟踪

摘要：在基于滑模观测器（SMO）的无传感器FOC中，我们获得了包含转子位置信息的反电动势分量 eα 和 eβ。然而，直接从反正切计算位置角 θe 得到的信号含有大量噪声，且无法直接提供平滑的速度信息。锁相环（PLL）作为一种经典的闭环跟踪系统，能够从含噪的反电动势信号中提取出平滑、连续的转子位置与速度估计。本文将从锁相环的基本原理出发，结合帕克（Park）变换，详细推导其在FOC中的应用，并提供简洁的C语言实现。

一、 锁相环的基本概念与原理

锁相环本质上是一个相位反馈控制系统，其核心目标是使一个内部可控振荡器的相位与一个输入参考信号的相位同步。

在一个典型的软件PLL中，它通常包含三个基本部分：

  1. 相位检测器（Phase Detector, PD）：比较输入信号与内部估计信号的相位差，输出一个与相位误差成正比的误差信号 ϵ。
  2. 环路滤波器（Loop Filter, LF）：通常是一个PI控制器，对误差信号 ϵ 进行滤波和调节。其输出是估计的角频率 ω^。
  3. 压控振荡器（Voltage-Controlled Oscillator, VCO）：在数字系统中，这表现为一个积分器。它将估计的角频率 ω^ 积分，得到估计的相位角 θ^。这个 θ^ 会反馈回相位检测器，形成闭环。
          [SMO Output]                 Phase            Loop          VCO
          e_α, e_β          --->       Detector   --->  Filter  ---> (Integrator)
           (Noisy)         [ε(θ-θ̂)]   [PD: e_d]     [PI]  [ω̂]       [θ̂ = ∫ω̂ dt]
                             ^                                          |
                             |                                          |
                             --------------------------------------------
                                          Feedback (cosθ̂, sinθ̂)

在FOC的上下文中，输入信号是滑模观测器估算出的反电动势矢量 e→=[eα,eβ]T，其相位包含了真实的转子位置角 θ。PLL的目标就是让内部估计的角度 θ^ 紧紧跟踪这个 θ。

二、 从帕克变换推导相位误差信号

将滑模观测器输出的反电动势矢量 [eα,eβ]T 进行帕克变换，变换到以 θ^ 为基准的 d-q 坐标系中：

[edeq]=[cos⁡θ^sin⁡θ^−sin⁡θ^cos⁡θ^][eαeβ]

其中，θ^ 是我们当前估计的转子角度。

根据之前的推导，真实的反电动势在α-β坐标系下为：

eα=ωeψfsin⁡θeβ=−ωeψfcos⁡θ

一般定义E=ωeψf为反向电动势的幅值，其中 ωe 为电角速度，ψf 为永磁体磁链。

将上述真实表达式代入 ed 和 eq 的公式：

ed=cos⁡θ^⋅(ωeψfsin⁡θ)+sin⁡θ^⋅(−ωeψfcos⁡θ)=ωeψf(cos⁡θ^sin⁡θ−sin⁡θ^cos⁡θ)=ωeψfsin⁡(θ−θ^)eq=−sin⁡θ^⋅(ωeψfsin⁡θ)+cos⁡θ^⋅(−ωeψfcos⁡θ)=−ωeψf(sin⁡θ^sin⁡θ+cos⁡θ^cos⁡θ)=−ωeψfcos⁡(θ−θ^)

关键推导：当估计角度 θ^ 非常接近真实角度 θ 时，即相位误差 Δθ=θ−θ^ 很小时，有 sin⁡(Δθ)≈Δθ，cos⁡(Δθ)≈1。因此：

ed≈ωeψf⋅(θ−θ^)≈θ−θ^=Δθeq≈−ωeψf=−E

这个公式揭示了一个重要的关系：在 d-q 坐标系下，反电动势的 d 轴分量 ed 正比于角度估计的误差 (θ−θ^)，比例系数是反电动势的幅值 ωeψf。

锁相状态分析：

当估计角度 θ^ 完全锁定在真实角度 θ 上时，即 θ^=θ（相位误差 Δθ=0）：

ed=ωeψfsin⁡(0)=0eq=−ωeψfcos⁡(0)=−ωeψf=−E

这意味着：

  • d 轴分量 ed=0：表示完全锁定，无相位误差
  • q 轴分量 eq=−E：表示反电动势全部落在 q 轴负方向上

三、 鉴相器设计

如何从反电动势中得到相位误差信号 Eerr

在实际系统中，我们无法获得理想的反电动势 eα,eβ，只有滑模观测器估算出的 E^α,E^β。我们直接使用这些观测值。

将观测到的反电动势用估计角度 θ^ 进行帕克变换：

E^d=cos⁡θ^⋅E^α+sin⁡θ^⋅E^βE^q=−sin⁡θ^⋅E^α+cos⁡θ^⋅E^β

根据之前得出的结论，在锁相状态下，当 θ^=θ 时，Ed=0。因此，构造误差信号为：

Eerr=Edtarget−E^d=0−E^d=−E^d

即：

Eerr=−(cos⁡θ^⋅E^α+sin⁡θ^⋅E^β)

根据之前ed≈Δθ的结论,并定义θerr=θ−θ^,可以得到：

Eerr=−E^d≈−Δθ=−(θ^−θ)=θ−θ^=θerr

四、 环路滤波器（PI控制器）与速度估计

误差信号 ϵ 被送入一个PI控制器（环路滤波器）。控制器的输出被解释为估计的电角速度 ω^e。

ω^e(k)=Kp⋅ϵ(k)+Ki⋅∑j=0kϵ(j)⋅Ts

为什么PI控制器的输出是速度？
这里有两种相辅相成的理解方式：

  1. 从系统动态角度理解：误差 ϵ 本质上反映了角度跟踪的“滞后”或“超前”量。当电机加速时，真实角度变化加快，如果观测器/计算环节的响应速度不变，就会产生更大的跟踪滞后（即更大的正 ϵ）。这个滞后量 ϵ 可以直观地理解为一种“相位积累差”，其变化率与加速度相关。PI控制器的积分项对 ϵ 进行累积：ω^+=Ki⋅ϵ⋅Ts。这正好对应于速度是加速度的积分这一物理关系。比例项 Kp⋅ϵ 则提供快速的相位校正响应，是对积分过程的一种动态补偿。

  2. 从闭环控制与数学推导理解：我们从公式 ed≈ωeψf⋅(θ^−θ) 出发。将其重写为 (θ^−θ)≈ed/(ωeψf)。在PLL中，我们通过PI控制器来驱动这个误差 ed 趋于零。PI控制器的传递函数在频域中为 Kp+Ki/s。整个PLL闭环的作用就是让估计角度 θ^ 跟踪真实角度 θ。根据自动控制原理，对于一个跟踪相位的闭环系统，其前向通路中积分器（VCO）前的控制器输出，自然具有频率的量纲。因此，PI输出被定义为估计速度 ω^e 是闭环系统结构下的必然结果。

两种理解并不矛盾，第一种提供了更直观的物理图景，第二种则基于严格的系统框图与数学关系。在实践中，我们只需记住：PI控制器处理的是相位误差信号，其输出被定义为估计的转速。

五、 算法流程与C语言实现

基于以上推导，PLL的离散化实现步骤如下：

  1. 鉴相：计算误差信号 Eerr=−(cos⁡θ^⋅E^α+sin⁡θ^⋅E^β)。

  2. 环路滤波：将 Eerr 送入PI控制器，得到估计的速度。

    比例项:Pout=Kp⋅Eerr(k)积分项:Isum=Isum+Ki⋅Eerr(k)⋅Tsθ^˙e(k)=Pout+Isum

  3. （可选）速度滤波：对 θ^˙e 进行低通滤波以平滑噪声，得到 θ^˙e,flt。

  4. 积分得位：对滤波后的速度进行积分，更新位置估计值。

    θ^e(k)=θ^e(k−1)+θ^˙e,flt(k)⋅Ts

    注意对 θ^e 进行周期归一化（如模 2π）。

以下是简化的C语言代码框架：

typedef struct {
    // PI 参数
    float Kp;
    float Ki;
    float integral_sum; // 积分项累加值
    // 状态变量
    float theta_hat;   // 估计角度 θ_hat
    float omega_hat;   // 估计速度 ω_hat
    float lpf_alpha;   // 速度低通滤波系数
    float flt_omega;   // 滤波后速度
} PLL;

float PLL_Update(PLL *pll, float Ealpha_hat, float Ebeta_hat, float Ts) {
    float phase_error;
    float omega_unfiltered;

    // 1. 鉴相器：计算相位误差 E_err
    phase_error = -(cosf(pll->theta_hat) * Ealpha_hat + sinf(pll->theta_hat) * Ebeta_hat);

    // 2. 环路滤波器 (PI控制器)：输出为未滤波的速度估计
    pll->integral_sum += pll->Ki * phase_error * Ts; // 积分项
    omega_unfiltered = (pll->Kp * phase_error) + pll->integral_sum; // PI输出

    // 3. （可选）对速度进行低通滤波
    pll->flt_omega = pll->lpf_alpha * pll->flt_omega + (1.0f - pll->lpf_alpha) * omega_unfiltered;
    pll->omega_hat = pll->flt_omega;

    // 4. 积分器 (VCO)：更新估计角度
    pll->theta_hat += pll->omega_hat * Ts;
    // 角度归一化到 [0, 2π)
    pll->theta_hat = fmod(pll->theta_hat, 2.0f * PI);
    if (pll->theta_hat < 0) {
        pll->theta_hat += 2.0f * PI;
    }

    return pll->theta_hat; // 返回用于Park变换的角度
}

六、 总结

锁相环是提升无传感器FOC系统位置估计鲁棒性和平滑性的有效工具。它将角度提取问题转化为一个闭环跟踪控制问题。通过将滑模观测器得到的反电动势矢量投影到以估计角度定向的 d 轴上，巧妙地构造出与角度误差成正比的鉴相信号 Eerr。利用PI控制器处理此误差，其输出自然地收敛于转子的角速度，再经积分得到平滑、连续的角度估计。这种方法有效抑制了直接计算反正切带来的高频噪声，特别是在低速区域，显著改善了系统的性能。在实际调试中，需合理设计PI参数 Kp、Ki 以及速度滤波带宽，以平衡动态响应速度、抗噪能力和稳态精度。
