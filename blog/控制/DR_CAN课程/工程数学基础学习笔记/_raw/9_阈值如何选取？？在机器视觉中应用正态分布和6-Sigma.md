**从项目需求说起**

需要在一个流水线上通过相机拍照判断传送带上的产品是否覆盖有透明塑料膜，有则为合格品，反之为不合格品。

![alt text](assets/images/image-28.png)

**实现分类的思路**

通过观察一组合格品和不合格品可以发现，覆盖透明塑料膜的产品有较多明显反光亮点。

将这部分特征明显的区域放大裁剪，经过黑白滤镜处理，统计图像中白色像素点数。

得到结果
- 合格品白色像素点数：3412
- 不合格品白色像素点数：908

可以明显发现有塑料膜的白色像素点数更多，可以以此为特征区分是否为合格品。


**阈值的选取**

拍摄10组合格品和不合格品，统计白色像素点数，会发现覆盖透明塑料膜的产品的白色像素点数的波动范围非常大，从两千多到四千多，因为环境光源的变化以及塑料膜上的褶皱形状存在差异，所以导致反光亮点数也差异巨大。

| 测试组 | 合格品 | 不合格品 |
| ------ | ------ | -------- |
| 1      | 3412   | 937      |
| 2      | 4351   | 924      |
| 3      | 4121   | 915      |
| 4      | 3171   | 908      |
| 5      | 3283   | 943      |
| 6      | 2836   | 935      |
| 7      | 4131   | 944      |
| 8      | 4279   | 932      |
| 9      | 4311   | 923      |
| 10     | 3587   | 936      |

直观上，合格品的数值都在2000以上，不合格品的数值都在1000以下。
可以设置阈值2000或1000，高于阈值判断为合格品，低于阈值判断为不合格品。

如何用更科学的手段来确定这个值？


**概率论知识回顾**

由于塑料膜覆盖在零件上的状态是随机的，相机本身的误差也是随机的，对于这些随机变量来说，其概率分布符合正态分布。

$$
X=(\mu,\sigma^2)
$$

其中$\mu$是期望值（平均值），$\sigma^2$是方差。

- 在一个标准差之间，大概有68%的概率，$\mu$落在$\mu\pm1\sigma$的范围内。
- 在三个标准差之间，大概有99.7%的概率，$\mu$落在$\mu\pm3\sigma$的范围内。

![alt text](assets/images/image-29.png)


比如统计某城市成年男性的身高，
期望（平均）值为$\mu=170cm$，方差为$\sigma^2=10cm^2=100cm$。

$$
X=(\mu=170,\sigma^2=100)
$$

那么其概率分布就符合正态分布：

![alt text](assets/images/image-30.png)

其中:
- 68.27%的人的身高在$\mu-\sigma=160cm$和$\mu+\sigma=180cm$之间，
- 95.45%的人的身高在$\mu-2\sigma=150cm$和$\mu+2\sigma=190cm$之间，
- 99.73%的人的身高在$\mu-3\sigma=140cm$和$\mu+3\sigma=200cm$之间。

于是可以大胆预测，若小明是该城市的成年男性，那么其身高99.73%的概率在140cm~200cm之间。


**6-Sigma**

> "六个西格玛是指在正态分布假设下生产的产品中介于六个标准差并且允许制程有1.5个标准差偏移下，有99.99966%的产品是没有质量问题的（每一百万中有3.4个有缺陷）。" ————wikipedia

| $\sigma$ | 良品率    | 次品率   | 每百万残次品数 |
| -------- | --------- | -------- | -------------- |
| 3σ       | 93.3%     | 6.7%     | 66807          |
| 5σ       | 99.977%   | 0.023%   | 233            |
| 6σ       | 99.99966% | 0.00034% | 3.4            |

**注：以上数据均考虑制程1.5σ偏移**


**感受6σ下的质量控制**

快递

| 总包裹量（每天） | 3σ丢失包裹 | 5σ丢失包裹 | 6σ丢失包裹 |
| ---------------- | ---------- | ---------- | ---------- |
| 100000000        | 6700000    | 233000     | 340        |

1亿包裹×6.68% = 668万个（3σ）

生产设备

| 每日生产量 | 3σ出现问题时间 | 5σ出现问题时间 | 6σ出现问题时间 |
| ---------- | -------------- | -------------- | -------------- |
| 200        | 13次/天        | 1次/21天       | 1次/4年        |

200×6.68% ≈ 13.4次/天（3σ）


**回顾分类的需求**

根据测试组的统计数据计算合格品和不合格品的期望值和方差，在同一张图中绘制他们的正态分布曲线。

存在两种情况

两曲线6σ位置不重合，阈值之间选取他们之间的位置。

![alt text](assets/images/image-31.png)


两曲线6σ位置重合

选取阈值为合格品的6σ位置作为阈值
- False Dismissal漏检（不会将不合格品判断为合格品，但可能将合格品判断为不合格品）
选取阈值为不合格品的6σ位置作为阈值
- False Alarm假警报（不会放过有瑕疵的零件，但是可能将合格品判断为不合格品）

![alt text](assets/images/image-32.png)


如之前的测试数据：

| 测试组       | 合格品   | 不合格品 |
| ------------ | -------- | -------- |
| 1            | 3412     | 937      |
| 2            | 4351     | 924      |
| 3            | 4121     | 915      |
| 4            | 3171     | 908      |
| 5            | 3283     | 943      |
| 6            | 2836     | 935      |
| 7            | 4131     | 944      |
| 8            | 4279     | 932      |
| 9            | 4311     | 923      |
| 10           | 3587     | 936      |
| $\mu/\sigma$ | 3785/541 | 930/12   |

- 合格品 $\mu-6\sigma=3785-6*541=53$
- 不合格品 $\mu+6\sigma=930+6*12=1002$

可以发现他们是重合的，选择False Alarm假警报策略，宁愿将合格品判断为不合格品，也不要漏检放过一个不合格品。
因此选择阈值不合格品的6\sigma之外的数如1050作为阈值 

另外可以发现

合格品 $\mu-6\sigma=3785-5*541=1080$

1050这个数在合格品的5\sigma之外，因此根据之前的计算，合格品被错判为不合格品的概率为0.023%，用之前每日生产200个的案例来计算，就是每21天会错判一次。

**自动更新阈值**

随着测试和生产的合格品和不合格品数据的增加，计算的期望值和方差就会越准确反映实际的概率分布，因此由此计算的阈值就会更准确，这个重新计算期望、方程、更新阈值的过程通过编程实现，某种程度上也是一种人工智能和机器学习。
